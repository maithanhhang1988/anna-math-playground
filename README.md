# 🌸 Vườn Toán Của Anna (Anna's Math Garden) 🌸

Một ứng dụng học toán vui nhộn và đầy màu sắc dành cho các bé, đặc biệt thiết kế cho công chúa nhỏ Anna! 👑

![Dự án Vườn Toán Của Anna](public/background.png)

## ✨ Tính năng nổi bật
- **Học thông qua trò chơi**: Các bài toán tìm Thừa số, Số bị chia, Số chia được lồng ghép vào câu chuyện cổ tích về Thỏ Trắng, Đám mây và Công chúa Anna.
- **Cấp độ đa dạng**: Từ "Khởi động" 🌼 đến "Tăng tốc" 🦋 và cuối cùng là "Về đích" 👑.
- **Phản hồi âm thanh**: Âm thanh vui nhộn khi trả lời đúng, khích lệ khi trả lời chưa chính xác.
- **Nhật ký phép thuật**: Theo dõi kết quả học tập và nhận lời khuyên từ "Quân sư Cú Mèo" 🦉.
- **Giao diện hiện đại**: Sử dụng **Tailwind CSS v4** và **Lucide React** cho trải nghiệm người dùng tuyệt vời.

## 🚀 Công nghệ sử dụng
- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide React** (Icons)

## 🛠️ Cài đặt và Phát triển

### Yêu cầu hệ thống
- Node.js (phiên bản 18 trở lên)
- npm hoặc yarn

### Các bước cài đặt
1. Clone repository:
   ```bash
   git clone https://github.com/maithanhhang1988/anna-math-playground.git
   cd anna-math-playground
   ```
2. Cài đặt dependency:
   ```bash
   npm install
   ```
3. Chạy môi trường phát triển:
   ```bash
   npm run dev
   ```
4. Build dự án cho môi trường thực tế:
   ```bash
   npm run build
   ```
